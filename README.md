本项目是基于alas的claude code修改 自用 版本，除过修改极个别项目外，与原版功能并没有差异，修改的项目包括：取消了原版对侵蚀一任务超过3000ap自动短猫的限制，加入了对侵蚀一过程中黄币的最低保留线和获取目标线的自定义以及大世界最后一天不再侵蚀一而短猫的ap线，并增加了mumu模拟器12安卓设备的定时重启功能（请不要打开mumu模拟器中的关闭最后一个安卓设备后推出客户端设置，并且该功能是通过mumu模拟器12官方提供的mumumanager实现，对于其他模拟器无效）

Alas 是一款免费开源软件，地址：https://github.com/LmeSzinc/AzurLaneAutoScript
